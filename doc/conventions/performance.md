# パフォーマンス規約

## バンドル

- CodeMirror の言語パックは、開いたファイルの拡張子に応じて **動的 import** する。静的 import で全言語を同梱しない。
- 初期表示に不要なコンポーネント（検索ドロワー、設定ダイアログ、Markdown プレビュー）は `React.lazy` で遅延読込する。
- 初期 JS の予算を定める（目安: gzip 後 300 KB 以下）。CI でビルド成果物のサイズを確認し、超過したら失敗させる。
- 依存を追加するときは bundlephobia 等でサイズを確認し、PR に記載する。

## 描画

- 数千ノードになり得るファイルツリーは **仮想化** する。
- ストアはセレクタで購読し、無関係な更新で再描画させない（[state.md](state.md)）。
- 長いリスト（検索結果、ブックマーク）にも同様に上限またはページングを設ける。
- `useMemo` / `useCallback` は、計測して効果が分かる場合にのみ使う。

## 通信

- 取得済みのファイル本文はセッション内でキャッシュして再取得しない。
- 検索は送信（Enter）で実行する。入力のたびに検索する UI にする場合はデバウンスする。新しい検索を始めたら、進行中のリクエストを中断する（`AbortController`）。結果は上限（`MAX_SEARCH_RESULTS`）で切る。
- Service Worker は GitHub API の GET を NetworkFirst でキャッシュする。静的資産は precache する。
